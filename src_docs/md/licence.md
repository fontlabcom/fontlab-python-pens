# Licence and attribution

The repository Apache 2.0 licence and each retained component notice apply to their respective material. This website does not replace or broaden those grants.

- [LICENSE](assets/LICENSE) — exact retained legal bytes.
- [NOTICE](assets/NOTICE) — exact retained legal bytes.

The pens ported from fontTools keep their MIT licence and copyright notice, listed in `NOTICE` with the derived files. The rest of the package is Apache 2.0.

## Current English browser payload

The build requires fly-january 0.4.0 or later (remote theme assets). The [browser-component record](assets/current-frontend-notices.json) covers the previously qualified Fly assets and MaterialX 10.1.8, with exact upstream notices, package archives and source maps.

The [English-only omission manifest](assets/english-search-omissions.json) binds all 35 unused lunr-languages 1.20.0 helpers, including Wordcut and TinySegmenter. The build rejects theme/search-language, corpus, vendor-set/hash and local HTML-reference drift before removing them. Seven MaterialX assets retain their upstream bytes. Fly rescales rem lengths in two MaterialX stylesheets. The manifest records their original and generated hashes. Historical complete outputs remain recovery evidence; omitted helpers are not represented as currently distributed or relicensed.

The main source map retains 211 preferred sources, including 128 exact NPM source matches; the worker map retains 13 sources, including Lunr 2.3.9. The exact clipboard distribution embeds its dependencies; select, good-listener and delegate retain their upstream README MIT link and Zeno Rocha attribution, without invented standalone licence text or dates. CSS maps retain source names without embedded source bodies.

Material Design icons retain the Pictogrammers notice and Apache 2.0 icon terms or specifically stated underlying terms; code is MIT. Font Awesome Free retains Fonticons attribution and CC-BY 4.0 terms. Octicons retains GitHub's MIT notice; Lucide retains ISC and inherited notices. Of 45 observed ordered SVG path tuples, 43 match installed MaterialX icon path tuples exactly, including `fontawesome/solid/caret-down.svg` used by `--md-version-icon`. Its unchanged CSS header identifies Font Awesome Free 7.1.0, Copyright 2025 Fonticons, Inc., and CC-BY-4.0 icon terms; the full Font Awesome notice remains available below. The official Font Awesome 7.1.0 NPM caret SVG has different raw path bytes from the installed icon and CSS. The two unmatched Lucide focus/download tuples retain their pinned SCSS attribution. No unchanged-primary SVG, whole-geometry or optimizer-recipe equivalence is claimed.

The site loads FontLab’s menu and footer from i.fontlab.com, fonts from Adobe Fonts and Google Fonts, PhotoSwipe from jsDelivr, and Fly CSS and JavaScript from fontlab.dev.
